# Phase 1.2 — Metals Universal Export Adapter

This bundle installs a non-destructive adapter into `C:\Users\DevonLockard\InvestmentPlatform`.

Start with `docs/PHASE_1_2_RUNBOOK.md`.

The adapter reads the standalone Metals platform, dynamically loads the existing Universal v1 contract definitions, creates seven canonical datasets, packages supporting evidence, computes SHA-256 checksums, and rejects contract-invalid output.
