# Phase 3.2 — Historical Validation Framework

## Mission

Determine whether the universal scoring system has measurable predictive value using reproducible, point-in-time, walk-forward validation.

## Subphases

1. Phase 3.2.1 — Historical validation contracts
2. Phase 3.2.2 — Walk-forward backtesting engine
3. Phase 3.2.3 — Ranking and calibration metrics
4. Phase 3.2.4 — Benchmark comparison engine
5. Phase 3.2.5 — Cross-asset validation
6. Phase 3.2.6 — Validation reporting and certification

## Core principle

Historical validation must use only information that would have been available on the prediction date. Future prices, revised datasets, and later model versions must never leak into the prediction process.
