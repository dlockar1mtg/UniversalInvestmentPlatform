# Phase 5.5.1 — Monitoring Contracts and Policy Bundle

Phase 5.5.1 establishes immutable contracts for post-decision monitoring and controlled reoptimization.

- Baselines retain the certified source run and output fingerprint.
- Observations and monitoring windows enforce timezone-aware, unique, bounded evidence.
- Thresholds define ordered watch, material, and critical boundaries by drift category.
- Monitoring policy fingerprints are stable across threshold input order.
- Drift signals and reoptimization triggers preserve severity and reason codes.
- Monitoring results reference new runs without mutating historical decisions or allocations.

Detection, outcome analysis, and trigger decisions remain reserved for later Phase 5.5 components.
