# Phase 5.2.7 — Ranking Explanation Engine

The explanation engine translates existing factor scores, penalties, portfolio
context, rank, and competition outcomes into deterministic human-readable
evidence. It identifies positive and limiting drivers, explains selection,
deferral, suppression, or exclusion, references competing winners, and retains
an immutable audit snapshot. It never recalculates or changes a decision, score,
rank, or disposition.
