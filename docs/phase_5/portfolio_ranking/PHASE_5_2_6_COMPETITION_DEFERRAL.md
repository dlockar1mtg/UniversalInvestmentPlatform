# Phase 5.2.6 — Competition and Deferral Rules

This component resolves ranked opportunities into `SELECTED`, `DEFERRED`,
`SUPPRESSED`, or `EXCLUDED` dispositions. It enforces batch and group capacity,
priority floors, duplicate suppression, deterministic ordering, explicit reason
codes, winner references, and immutable audit evidence. It does not recalculate
Phase 5.1 decisions or Phase 5.2 priority scores.
