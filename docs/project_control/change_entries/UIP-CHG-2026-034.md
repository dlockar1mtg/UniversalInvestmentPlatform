# UIP-CHG-2026-034 — Freeze Dashboard Product Specification and Make Dashboard Foundation the Active Execution Path

Date: 2026-08-22  
Status: APPROVED  
Type: DASHBOARD, ROADMAP, ARCHITECTURE, DATA_GOVERNANCE  
Approval authority: Devon Lockard

## Decision

Freeze `UIP Dashboard Product Specification V1` and the V7 visual target as the approved user-facing product contract.

Advance the active execution path from direct Stocks/ETF implementation to the certified dashboard/read-model foundation first. Stocks/ETF remains the next new analytical domain, but it must integrate through the approved domain-neutral presentation/read-model and application contracts rather than redefine the dashboard after the fact.

## Reason

The certified R3 backend is now sufficiently stable to define the product layer it must serve. Freezing the dashboard first prevents remaining domain/backend work from producing an interface that is technically correct but difficult to use, and ensures Stocks/ETF can be added without redesigning the application.

## Architecture impact

The hosted application must separate:

- certified analytical authority from UIP/domain outputs; and
- user/application state such as transactions, accounts, cash, watch state, settings, roles, and sessions.

The next governed design target is a versioned presentation/read-model publication into the hosted application boundary. Render/PostgreSQL must not independently recreate or reinterpret analytical authority.

## Governance constraints preserved

- no universal cross-domain ranking;
- no transfer of native ranks/scores between domains;
- no automatic allocation policy;
- no automatic trade execution;
- missing remains missing;
- unsupported forecasts remain unavailable;
- unknown cost basis remains unknown;
- refresh remains fail-closed with last-good-state preservation;
- external Crypto/MTG collection/model workflows remain source-owned;
- future Stocks/ETF authority remains unavailable until separately certified.

## Certification impact

Dashboard implementation must be certified against both the product specification and the V7 visual acceptance record. Visual/product conformance is an explicit acceptance gate rather than an informal preference.

## Risk and cost impact

This change reduces redesign risk and avoids building duplicate analytical authority in the hosted application. It does not authorize a new paid service or change the final remote-infrastructure decision.
