\# Universal Investment Intelligence Platform



The Universal Investment Intelligence Platform integrates analytics and

standardized outputs from multiple investment intelligence systems.

\- Crypto Intelligence

\- Metals Intelligence

\- Magic: The Gathering Intelligence

\- Housing Intelligence

\- Macro Intelligence

\## Repository Structure



\- `config/` — shared platform configuration

\- `data/` — integration, validation, and reference data

\- `docs/` — architecture and operating documentation

\- `environment/` — reproducibility and environment records

\- `exchange/` — standardized platform exports

\- `foundation/` — Phase 0 planning and inventory

\- `registry/` — platform registration information

\- `schemas/` — universal data contracts

\- `scripts/` — operational and validation scripts

\- `tests/` — automated tests



\## Important Design Principle



Each investment platform remains independently operable. The Universal

Investment Intelligence Platform consumes standardized exports rather than

requiring every platform to run inside one application.
